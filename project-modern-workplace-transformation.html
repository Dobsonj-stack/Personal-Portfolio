Modern Workplace Transformation – Marian College

Delivered a cloud-first Microsoft 365 and Intune transformation with minimal disruption.

Overview

Supported a full modern workplace transformation, migrating the site from on-premises Active Directory and file servers to a cloud-first Microsoft 365 and Intune environment.

Devices were removed from legacy Active Directory and re-enrolled into Intune with modern management, security baselines, and compliance policies applied. In parallel, all documents were migrated from on-prem file servers into SharePoint Online, enabling secure cloud access and improved collaboration.

The project was completed with minimal disruption while supporting staff through the transition.

Technologies Used

  • Microsoft Intune
  • Azure AD / Entra ID
  • SharePoint Online
  • Windows device management
  • Cloud migration tooling

Key Outcomes

  • Eliminated reliance on on-prem Active Directory.
  • Centralised device management through Intune.
  • Migrated legacy file server data to the cloud.
  • Improved security, mobility, and remote-work capability.
